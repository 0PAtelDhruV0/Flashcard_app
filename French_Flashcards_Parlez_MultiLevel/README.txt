PARLEZ · MULTI-LEVEL FRENCH FLASHCARDS (VERSION 2)

Open French_Flashcards_Parlez.html in a modern web browser.
Choose one of five independent level decks: A1, A2, B1, B2, C1.
Each level includes Vocabulary, Grammar and Sentences.

270 total flashcards, with French audio, meanings, usage explanations,
example sentences, reveal/blur controls and level-specific progress.

Use the optional per-level CSV and JSON files to study or edit the source.
The combined CSV file contains all 270 cards. Custom cards made within
the app are saved locally by the browser, not automatically to the CSV files.
Use Export in the app to back them up.

Speech playback requires a browser/device with French voices installed.
No remote service is used to load cards and no account is needed. Browser
local storage availability can vary for local HTML files, especially on iPad;
export your cards if you want a dependable backup.

On iPad, publish this single HTML file to GitHub Pages and open it in Safari
for the most reliable experience. Audio starts after tapping Listen.
