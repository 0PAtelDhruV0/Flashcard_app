GitHub source

Deckflow reads CSV decks from a public GitHub repository. Changing the repository will load its subjects and decks without editing this HTML.

Organize any subject: create folders such as:

decks/Languages/French/My_French_Deck.csv
decks/Languages/Japanese/Hiragana.csv
decks/Science/Biology/Cells.csv
decks/History/World_History/Ancient_Rome.csv

For each card, the CSV needs a front and answer, such as front,back,example,note. French decks with french,meaning,example_fr,example_en,note still work. Files ending in _All_Decks.csv are ignored to avoid duplicates.
